SERVICIO ADICIONAL
🚀

Implementación Integral EduOne

El colegio entrega la información y nuestro equipo realiza toda la configuración inicial completa. Recibes la plataforma lista para comenzar a trabajar.

  • ✓ Equipo EduOne realiza la configuración
  • ✓ Registro completo de estudiantes
  • ✓ Registro de profesores y directivos
  • ✓ Creación de grados, cursos y asignaturas
  • ✓ Configuración de horarios y periodos
  • ✓ Creación y entrega de usuarios
  • ✓ Revisión general y acompañamiento
  • ✓ Plataforma lista en hasta 7 días hábiles
